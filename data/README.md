# Data Directory

This directory contains selected processed datasets and model-derived outputs used in the Manchester City football modeling project.

## Data Availability

Raw third-party datasets are not redistributed in this repository.

The project uses historical football data from sources including Football-Data.co.uk, FBref, ClubElo, Understat, FotMob, and Transfermarkt. These datasets remain subject to their respective providers' terms and conditions.

Detailed source attribution, collection notes, transformations, and dataset lineage are documented in:

[`docs/DATA_SOURCES_AND_PROVENANCE.ipynb`](../docs/DATA_SOURCES_AND_PROVENANCE.ipynb)

## Directory Structure

### `processed/`

Contains selected datasets that were cleaned, reorganized, merged, or transformed from the original source data for use in the research notebooks.

Current files include:

- `team_match_long_updated.xlsx`  
  Processed Premier League match-level team data used in the team-strength analysis.

- `team_match_long.csv`  
  Earlier processed long-format Premier League dataset retained because it is referenced by parts of the historical modeling pipeline.

- `e1_team_match_long_all.csv`  
  Processed Championship team-match dataset used in promoted-team and cross-league analysis.

These files are included primarily to document the model-development workflow. Some historical notebooks may still depend on source files or directory structures that are not redistributed here.

### `derived/`

Contains intermediate and final outputs generated by the modeling notebooks.

Examples include:

- opponent-adjusted team-strength results
- scalar and unified strength indices
- Bayesian model inputs and estimated parameters
- historical posterior strength estimates
- promoted-team prior estimates
- 2026/27 preseason priors
- saved historical prediction results

Unlike the original source data, these files represent outputs produced during the modeling process.

## Reproducibility Note

This repository is primarily intended as a record of the modeling process and results rather than a fully self-contained reproduction package.

The research notebooks preserve their executed outputs, assumptions, model comparisons, and interpretation. A complete rerun of every historical stage may require third-party raw datasets that are not included in this repository.

The standalone forecaster in `../forecaster/` is designed to run independently of the historical raw-data pipeline.
