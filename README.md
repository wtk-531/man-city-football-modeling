# man-city-football-modeling

Mathematical modeling of Manchester City performance using Bayesian team-strength updates, dynamic-state analysis, and probabilistic score forecasting.

## About This Project

I'm an undergraduate studying applied mathematics and a Manchester City fan. I started this project to explore how mathematical modeling can help us understand football, put what I've learned into practice, and develop my modeling skills.

I'm sharing the work as part of that learning process, and I welcome feedback, suggestions, and discussions with others interested in football analytics, Bayesian methods, or applied mathematics.
